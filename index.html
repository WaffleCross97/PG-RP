How ModelApplier Works (Simplified):

  • Item Name: The only name you need to provide
  • Three files are created with the SAME name:
    1. items/{item_name}.json ← Tells ModelApplier what model to use
    2. models/item/{item_name}.json ← Your 3D model
    3. textures/item/{item_name}.png ← Your texture
  • In-game usage:
    1. Rename any item to your Item Name
    2. ModelApplier looks for items/{item_name}.json
    3. Finds "model": "minecraft:item/{item_name}"
    4. Uses models/item/{item_name}.json (your 3D model)
    5. Uses textures/item/{item_name}.png (your texture)
